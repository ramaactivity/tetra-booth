## Potong 2 inci per job (bukti tanpa kertas)

Driver DNP menyimpan pemotong di DEVMODE (fitur GPD `CUTTERCONTROL`, PrintTicket `<prefix>:DocumentCUTTERCONTROL` = `CUT_STANDARD`/`CUT_2INCH`). Namespace prefix mengandung versi Windows (`http://schemas.microsoft.com/windows/printing/oemdriverpt/DS_RX1/10.0.22621.3810/`), jadi jangan ditulis mati.

Temuan:
1. Printing Preferences dari Settings (yang diubah Rama) menyimpan **DEVMODE per pengguna**. `new PrinterSettings{PrinterName}` membaca DEVMODE itu (`CUT_2INCH`), sementara default antrean (`Get-PrintConfiguration`) tetap `CUT_STANDARD`. Karena itu lembar 3–4 terpotong. **Selama setelan ini aktif, cetak 4R juga ikut terpotong dua** kalau aplikasi tidak menimpanya per job.
2. Prototipe (`C:\TetraBooth\scratch\cutproto\cut.cs`, `spool.cs`; tidak di-commit):
   - `PrinterSettings.GetHdevmode()` → `PTConvertDevModeToPrintTicket` (job scope).
   - Ubah `Option` pada fitur yang namanya berakhiran `:DocumentCUTTERCONTROL`.
   - `PTConvertPrintTicketToDevMode` (base = user default, job scope).
   - `PrinterSettings.SetHdevmode` + `PageSettings.SetHdevmode`.
   - Hasil baca balik: `CUT_2INCH` → `CUT_STANDARD` → `CUT_2INCH` sesuai perintah, kertas tetap `(6x4)`.
3. **Sampai ke spooler:** job kecil ke antrean offline `DS-RX1 (Copy 1)` (USB002, tanpa perangkat, tidak mencetak), lalu `EnumJobs` level 2 → `pDevMode` job → PrintTicket:
   ```
   job 11 'CUT_2INCH'    → DEVMODE di spooler: ns0000:CUT_2INCH
   job 12 'CUT_STANDARD' → DEVMODE di spooler: ns0000:CUT_STANDARD
   ```
   Kedua job dihapus. Job lama Rama di antrean itu (Id 80, 7 September) tidak disentuh.
4. Default antrean `DS-RX1` tidak diubah (tetap `CUT_STANDARD`). Setelan per pengguna Rama sekarang `CUT_2INCH`.

Catatan teknis untuk implementasi:
- Hanya P/Invoke ke `prntvpt.dll` + `ole32.dll` (`CreateStreamOnHGlobal`), tanpa WPF/`System.Printing`. Cocok di `TetraCamera.Print.Windows` (`[SupportedOSPlatform("windows")]`).
- Butuh COM interop bawaan (`ComTypes.IStream`). Kalau Camera Service di-publish dengan trimming/AOT: `BuiltInComInteropSupport=true`, atau `IStream` lewat `ComWrappers`/vtable manual.
- Driver tanpa fitur `DocumentCUTTERCONTROL` (Print to PDF, Epson) dilewati tanpa error.

**Aturan yang cocok dengan semua lembar (termasuk #1–#4):** terpotong ⇔ dialog Printing Preferences yang terakhir di-OK (antrean mana pun) = Enable. Isi DEVMODE job, antrean yang dipakai, dan setelan yang ditulis program tidak berpengaruh.

Bukti tambahan (tanpa kertas):
- DEVMODE per pengguna hasil program **identik byte-per-byte** dengan hasil dialog (Enable: byte OEM 284 = 1 + teks Unidrv `CUT_2INCH`), di `DevModePerUser` dan `DevModes2`.
- DEVMODE job di spooler memuat opsi yang diminta (job 30/31).
- Process Monitor saat dialog di-OK: hanya `RegSetValue` ke `HKCU\Printers\DevModePerUser\<antrean>` (spoolsv) dan `DevModes2\<antrean>` (rundll32), lalu rundll32 memuat `C:\Windows\System32\CSJCYLM.DLL` ("CY Language Monitor", ekspor `InitializePrintMonitor`/`MonitorIoControl`, string `CNTRL`, `CUTTER`, shared memory `Global\CSJCY.SHMEM/SHVAL`). Tidak ada file/registry lain dan tidak ada I/O USB yang terlihat.
- Isi `Global\CSJCY.SHVAL` (4 KB) dan `SHMEM` (30 MB) **tidak berubah** antara dialog Disable dan Enable.
- Tidak ada job yang muncul di antrean saat dialog di-OK.
- Kesimpulan: keadaan pemotong kemungkinan disimpan di printer (fitur firmware "Printer V.1.10 or later") lewat jalur yang tidak terlihat dari user mode. Cara otomatis butuh info protokol dari DNP (SDK/`MonitorIoControl`) atau reverse engineering lebih dalam.

**Kalibrasi posisi:** K1 (6.665) garis tengah di potongan kiri, K8/K11 (6.72–6.78) di potongan kanan → posisi pisau ≈ **y = 6.70**. Pita abu kiri sedikit lebih lebar di semua nilai 6.72–7.85: pisau tidak persis di tengah kertas fisik (sisa ±0,1–0,3 mm). Nilai akhir: `--print-offset "7.335,6.70"`.

**Kertas:** W-022 4 lembar (#1–#4) + 11 lembar tambahan (K1–K11) = **15 lembar** DNP. Counter booth tidak mencerminkan lembar dari skrip kalibrasi.

**Status akhir setelan printer:** dialog terakhir = **Enable** (langkah E, 01:5x). Semua cetakan, termasuk 4R, terpotong sampai dialog diset Disable. Antrean "DS-RX1 2inch" (USB001) tetap ada; tidak berguna untuk DNP ini, boleh dihapus (admin).
