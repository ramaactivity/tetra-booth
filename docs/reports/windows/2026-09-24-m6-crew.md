## 2. Manual dengan printer PDF

Config benar: `--printer="Microsoft Print to PDF" --paper-4r=A5 --paper-2x6x2=A5 --print-to-file=$W\prints`. Bentuk `=` dipakai karena bentuk dengan spasi masih diabaikan (M-008 no. 1).

### 2a. Test print (`--camera=webcam`)

- PIN baru 2468 dibuat (dua kali), roll diisi 25 → "Kertas 25 / 25 lembar · Kertas hampir habis".
- Test print → catatan "Terkirim ke printer", `test-A3LbTdfTQB.pdf` (70 KB) terbentuk 2,5 s setelah klik.
- Log main: `[print] selesai test-A3LbTdfTQB · kertas 24`. Menu: "Kertas 24 / 25 lembar". `print_jobs`: `done`.

### 2b. Print gagal → cetak ulang (`--camera=simulated`)

Run dengan `--paper-2x6x2=TidakAda`, satu sesi lewat tap (mulai → LANJUT → CETAK → SELESAI):
- Log: `[print] GAGAL r5F7zmUEWt: paper_not_supported 2x6x2 butuh nama kertas dari config (--paper-2x6x2); 'TidakAda' tidak ada di driver`.
- `print_jobs`: `failed`, `paper_not_supported: …`.
- Attract: peringatan kecil di **pojok kanan bawah** (titik merah + teks abu-abu) berbunyi "Cetak gagal: 2x6x2 butuh nama kertas dari config (--paper-2x6x2); 'TidakAda' tidak ada di driver".
- Menu crew → "Cetak gagal": `15.49.25 · 1× · paper_not_supported: …` + tombol **Cetak ulang**.

Run berikutnya dengan config benar → Cetak ulang:
- `r5F7zmUEWt-rmufajobm.pdf` terbentuk, log `[print] selesai r5F7zmUEWt-rmufajobm · kertas 23`.
- Daftar "Cetak gagal" → "Tidak ada".

## Temuan kecil (M-010)

1. Peringatan cetak gagal di attract (layar tamu) menampilkan teks teknis (`--paper-2x6x2`, "driver"). Saran: di layar tamu cukup kalimat pendek, mis. "Printer bermasalah, hubungi crew". Detail teknis tetap di menu crew.
2. Menu crew tidak langsung menyegarkan counter kertas setelah Cetak ulang: log `kertas 23`, menu masih "24 / 25" sampai refresh 5 s berikutnya.
3. Status crew di layar portrait terlihat "Camera Service mati" hanya karena uji portrait memakai `--no-spawn`. Bukan bug.
