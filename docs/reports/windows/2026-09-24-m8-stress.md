## 3. Rekomendasi untuk laptop event (setelan belum diubah, keputusan Rama)

1. Sebelum event: jalankan Windows Update sampai tuntas, termasuk "Optional updates → Driver updates", lalu restart. Ulangi sampai tidak ada update tersisa.
2. Selama periode event: **Pause updates** (Settings → Windows Update → Pause 1–5 minggu), atau set Active hours untuk jam event. Lebih kuat lagi: kebijakan "Do not include drivers with Windows Updates" (gpedit / `ExcludeWUDriversInQualityUpdate=1`) di laptop booth khusus, supaya driver grafis hanya diperbarui manual.
3. Aplikasi (M-016 sudah di `main`): pemulihan otomatis saat GPU process hilang. Tetap perlu uji sungguhan saat ada update driver berikutnya. Watchdog di luar proses main juga masih layak dipertimbangkan, karena main yang macet tidak bisa memulihkan dirinya sendiri (kasus run ke-1).

`getGPUFeatureStatus`:
- a: `gpu_compositing: enabled`, `2d_canvas: enabled`, `rasterization: enabled`, `webgl: enabled`.
- b: `gpu_compositing: disabled_software`, `webgl: enabled_readback`.
- c: semua `disabled_software`/`unavailable_software`.
- d: `2d_canvas: disabled_software`, compositing tetap GPU.

Kesimpulan:
- **Attract diam saja sudah ±430–450 MB total.** Animasi strip v2 ringan dan 60 fps di semua varian.
- **Lonjakan GPU terjadi saat sesi**, bukan di attract. Preview 1600 px (`fea7083`) hanya menurunkan ±100 MB (1.231 → 1.124).
- **Canvas 2D ber-GPU menyumbang ±500 MB** (d: 1.124 → 607). Dugaan: compose strip dan/atau decode raw 3000×2000 di canvas yang dipercepat menyimpan tekstur di GPU process (cache Skia). Sisanya ±480 MB ada di compositing.
- Mematikan GPU (b/c) memindahkan memori ke renderer (±650–800 MB WS), menurunkan kecepatan jadi 5–7 sesi/menit, dan menurunkan fps saat sesi ke 55. Total tetap ±1 GB. **Bukan solusi.**
- Usul untuk Mac:
  - Compose di `OffscreenCanvas` worker atau software 2D untuk canvas besar saja (bukan flag global), dan lepas bitmap (`ImageBitmap.close()`) setelah compose.
  - Batasi cache GPU (mis. `--force-gpu-mem-available-mb`/`--gpu-program-cache-size`) sebagai eksperimen.
  - Atau ubah kriteria menjadi "total ≤ X MB tanpa tren" untuk iGPU Windows.
