# W-023 Kamera Canon 60D lewat digiCamControl → hot folder, sesi penuh dengan DNP

Tanggal: 2026-09-25 (±02:05 WIB) · laptop booth Rama · basis `win@2f3f40d`+ (M-021, penerusan flag diperbaiki) · digiCamControl 2.1.7.0 (sudah terpasang, izin Rama) · Canon EOS 60D (USB, WPD OK setelah Rama mencabut-colok; Auto power off = Off) · DNP `DS-RX1`.

## Ringkasan

- **Lulus, dengan pemicu otomatis:** booth memicu shutter 60D lewat web server digiCamControl (`--hot-folder-trigger "http://localhost:5513/?CMD=Capture"`). Sesi 3 foto → review → cetak DNP 1 lembar (jatah W-023) → QR.
- Raw **5184×3456** (Large Fine). Transfer kamera → hot folder 0,32 s (log digiCamControl).
- Pemicu gagal (digiCamControl mati) → teks tunggu → A10 → **pulih sendiri** setelah digiCamControl dinyalakan lagi.
- Tidak diuji: shutter ditekan manual oleh Rama (sesi ini full auto tanpa Rama di depan kamera). Waktu kertas keluar tidak diamati.

## Setup digiCamControl

Dijalankan sekali untuk membuat setelan, lalu ditutup dan diubah (cadangan: `C:\TetraBooth\scratch\dcc-*.backup.json`):
- `C:\ProgramData\digiCamControl\settings.json`: `"UseWebserver": true` (port 5513, `AllowWebserverActions` sudah true).
- `C:\ProgramData\digiCamControl\Sessions\Session1.json`: `Folder` = `C:\TetraBooth\hot`, `DownloadOnlyJpg` = true, daftar file sesi lama dikosongkan (foto lama Rama di `Pictures\digiCamControl\Session1` tidak disentuh).

- Uji manual: `GET http://localhost:5513/?CMD=Capture` → 200, `DSC_0004.jpg` 5184×3456 masuk hot folder ±1 s kemudian.

## Pemicu gagal → pulih

digiCamControl ditutup, lalu sesi dimulai (`booth.cjs recover`, Print to PDF, data terpisah):

```
19:07:42.574 capture foto=1
19:07:46.758 capture gagal: pemicu shutter tidak bisa dihubungi: No connection could be made…
19:07:50.829 capture gagal (ulang)
19:07:50.856 camera_error                      ← layar A10 "Sebentar ya, kamera sedang disiapkan ulang" (11,3 s setelah mulai)
             (teks "Sebentar, menunggu foto dari kamera…" muncul 6,5 s setelah mulai)
+0,5 s       digiCamControl dinyalakan lagi
19:07:55.926 capture foto=1 → 19:08:06.033 capture gagal: Tidak ada foto baru di hot folder dalam 10 detik
             (web server sudah jawab, kamera belum selesai inisialisasi)
19:08:08.207 preview foto=1 · foto 2: 1,8 s · foto 3: 3,0 s → review (34 s setelah digiCamControl dinyalakan)
```

Catatan untuk Mac:
- Pemicu yang diterima web server saat kamera belum siap tidak menghasilkan foto. Timeout 10 s + retry menangani ini dengan benar.
- Kemungkinan kecil foto dari pemicu yang terlambat masuk sebagai foto berikutnya. Tidak terjadi di uji ini.

## Perbaikan terkait (sudah di `win@adec4a4`)

Booth sebelumnya **tidak meneruskan** `--hot-folder-trigger` ke Camera Service (flag ada di `VALUE_FLAGS`, tapi tidak ada di daftar `cameraServiceFlags`), jadi W-023 dengan pemicu tidak mungkin jalan di `main`. Sekarang diteruskan bersama `--print-offset` dan `--printer-2x6x2`.
