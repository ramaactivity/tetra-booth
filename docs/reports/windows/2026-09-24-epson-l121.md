## Temuan

### 1. Epson L121 tidak bisa dipakai lewat logika M4 saat ini (keputusan Mac, M-013)

Driver tidak menyediakan 4×6 dan A4 punya margin keras, sehingga booth selalu menolak (sesuai DECISIONS #27: lebih baik gagal daripada salah cetak). Kalau printer inkjet ber-margin mau dipakai sebagai cadangan atau untuk uji, butuh keputusan desain, misalnya:
- mode "ber-margin": izinkan `PrintableArea` lebih kecil dari kertas, lalu gambar 4×6 diletakkan di dalam area cetak (bisa beberapa per A4, lalu digunting);
- atau tetap tolak dan hanya uji jalur error dengan printer seperti ini.

Catatan: ukuran 10×15/borderless Epson mungkin ada di dialog Preferensi driver (DEVMODE privat Epson), tapi tidak terlihat lewat `PaperSizes`. Sesuai aturan tugas, preferensi printer tidak dibuka atau diubah.

### 2. Menu crew menampilkan "Printer belum terdeteksi" walau printer `ready` (kecil)

Camera Service mengirim `printer.status ready` saat start dan `system.health.printer = ready`, tapi kartu Status di menu crew tetap "Printer belum terdeteksi" (status `unknown`), kemungkinan karena event status pertama terkirim sebelum koneksi event booth tersambung dan tidak dikirim ulang. Saran: minta status saat koneksi event tersambung, atau pakai `health.printer` sebagai nilai awal.

### 3. "Terkirim ke printer" muncul walau gagal (kecil)

Setelah Test print, catatan UI "Terkirim ke printer" tetap tampil walaupun 0,3–0,8 s kemudian `print.failed` datang. Saran: ganti catatan dengan hasil akhir (selesai/gagal + kode) setelah event datang.

## Bersih-bersih

`$W\data` dihapus. Printer Epson: status Normal, JobCount 0, tanpa perubahan setelan.
