## Catatan

1. **60 menit belum terbukti.** Offline sebenarnya 13,5 menit. Mekanisme antrean tidak bergantung pada durasi, tapi kriteria Fase 2 menyebut 60 menit. Usul: ulangi 60 menit saat Rama ada. Proses uji harus berjalan terpisah dari sesi Claude Code (Task Scheduler / `Start-Process`), dan Wi-Fi diputus fisik atau lewat router, karena Windows menyambung ulang sendiri (menulis `connectionmode=manual` ke profil Wi-Fi = mengubah setelan Windows, tidak dilakukan).
2. Halaman tamu masih menampilkan tanggal UTC ("24 September 2026" untuk sesi 02:3x WIB 25 September), sudah dilaporkan di issue #1.
3. Log booth tidak mencatat kemajuan upload. Usul: `[upload] n file terkirim, sisa m` per menit supaya uji seperti ini bisa dibaca dari log.
