Catatan & usulan

  • Strip 2R hanya punya lebar teks ±40 mm. Nama 40 karakter akan dipadatkan ke sekitar 50–60% lebar huruf. Usulan: placeholder opsional {event_short} (mis. "Nadhira 17") khusus strip.
  • Placeholder tanggal baru: {date_long} = "10 Oktober 2026" (semua gaya wedding) dan {date_dot} = "10.10.26" (Film Monokrom, Photobox Klasik, Cover Majalah, kartu QR). Gaya lain memakai {date} apa adanya.
  • Selotip semi-transparan di Scrapbook menimpa sedikit sudut foto; ini disengaja dan tetap valid karena overlay boleh menutup tepi slot.
  • Kartu nama ditampilkan setelah dipotong (90×55). Aktifkan "guides" di Tweaks untuk melihat file 96×61 dengan garis potong (magenta) dan zona aman 4 mm (biru).
  • File siap pakai (overlay.png, background.png, JSON per frame, SVG kartu dalam mm) dibuat setelah owner memilih arah, supaya revisi tidak perlu diekspor ulang 45 kali.
